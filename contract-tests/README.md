# Scénarios contractuels

Ces fichiers décrivent des comportements métier indépendamment du langage du client. Ils peuvent servir de base aux tests XCTest du client macOS ou aux tests Rust du client Linux.

Le binaire `dcc-api-conformance` exécute déjà les principaux scénarios contre un serveur actif. Les fichiers JSON constituent la forme lisible et versionnable du contrat.
